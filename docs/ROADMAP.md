# خطة وظيفتي

## منجز
- **v1.0:** الواجهات الثلاث، المساعد الذكي، قوالب السيرة والإعلانات، الهوية البصرية، APK.
- **v2.0:** التحويل لليمن، العربية والإنجليزية، Supabase (حسابات وصلاحيات وملفات ولحظي)، الدخول بـ Google والجوال، السجل التجاري، رفع السيرة PDF، المحادثة، المقابلات، التقييم ونسبة الرد، إشعارات الوظائف المناسبة، الذكاء الاصطناعي الحقيقي، سياسة الخصوصية والشروط، حذف الحساب.
