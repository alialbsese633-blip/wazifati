# خطة وظيفتي

## المرحلة 1 · النسخة 1.0 (منجزة)
- الواجهات الثلاث (باحث، صاحب عمل، إدارة) بكامل الدورات
- المساعد الذكي بثلاثة أوضاع + 7 مهام ذكية
- 4 قوالب سيرة حصرية + 8 قوالب إعلانات
- الهوية البصرية والشعارات والأيقونات
- قاعدة البيانات `supabase/schema.sql` ودالة الذكاء الاصطناعي

## المرحلة 2 · الربط الحقيقي (4 أسابيع)
| الأسبوع | العمل |
|---|---|
| 1 | إنشاء مشروع Supabase وتشغيل schema.sql وتسجيل الدخول برقم الجوال (OTP) |
| 2 | استبدال البيانات التجريبية بقراءة وكتابة من القاعدة (الوظائف، الملف، الطلبات) |
| 3 | لوحة صاحب العمل والإدارة على القاعدة + رفع الشعارات والسير PDF إلى Storage |
| 4 | نشر دالة الذكاء الاصطناعي + إشعارات Push + اختبار مغلق |

## المرحلة 3 · الإطلاق (4 أسابيع)
- اختبار مغلق: 5 شركات و50 باحثاً في ولاية واحدة
- أول 100 وظيفة حقيقية قبل الإعلان للباحثين
- إشعارات واتساب، صفحات الشركات العامة، الباقات المدفوعة

## قبل الإطلاق العلني
- مراجعة متطلبات وزارة العمل وقانون حماية البيانات الشخصية في عُمان
- سياسة خصوصية وشروط استخدام
